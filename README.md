# NCM 转换器

将 NCM 音乐文件转换为 MP3 或 FLAC，保留歌曲信息和封面。

## 下载与安装

[下载与查看最新版本](https://github.com/dogdreamson555/ncm2play/releases/latest)

系统要求：Windows 10 1809（内部版本 17763）及以上的 64 位 Windows，包括 Windows 11。

下载版本页面中的 `NcmConverter-<版本号>-win-x64-setup.exe`，运行后按向导安装。安装包自带所需运行库，默认安装到当前用户目录；升级时直接运行新版安装包。


## 开始使用

1. 拖入 NCM 文件或文件夹。
2. 选择输出目录。
3. 点击“开始转换”。

默认的简单模式保留原音频格式和音频数据，写入可用的歌曲信息与原封面，并按源文件名输出。

## 功能

- 高级模式可选择 MP3 码率或 FLAC 压缩级别，批量更换封面，以及设置分类、命名和编号。
- 封面支持 JPEG、PNG、WebP、AVIF、HEIC/HEIF、BMP 和 ICO。
- 添加文件夹时自动扫描子文件夹；列表支持拖动排序和批量移除，移除只影响列表。
- 显示转换进度，支持取消；单个文件失败不影响其他文件。
- 重名文件自动追加序号，不覆盖已有文件，也不修改源文件。

## 使用须知

- MP3 转为 FLAC 不会恢复已经损失的音质。
- 专辑编号需要原音频中有有效曲序；缺失或冲突时可改用列表顺序编号。
- 部分带透明信息的 HEIC/AVIF 封面暂不支持，遇到时会明确提示。
- 当前不会保存界面设置，重新打开程序后需要重新选择。
